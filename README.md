A faster drop-in replacement for csv-reader 1.0.0. It parses broken CSV files with an indexOf-and-slice scanner and returns exactly the same answers (columns, rows, errors) as the reference implementation, using less CPU time. Verified identical output on all practice cases and 4,500 randomized differential tests, at roughly 1.85x the speed of the baseline in the full harness.

## Run it

```sh
node main.ts
```
